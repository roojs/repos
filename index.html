roojs package repositories

Official APT and DNF packages for roojs desktop projects. This page is generated from the published repository, not a hand-written list.

APT

Debian: Debian 13 (trixie). Ubuntu: Ubuntu 25.04 (plucky), Ubuntu 25.10 (questing), Ubuntu 26.04 (resolute). Architectures: amd64.

Add the signing key and the sources file, replacing @suite@ with your suite from lsb_release -cs:

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://roojs.github.io/repos/key.gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/roojs.gpg

curl -fsSL https://roojs.github.io/repos/sources \
  | sed "s/@suite@/$(lsb_release -cs)/" \
  | sudo tee /etc/apt/sources.list.d/roojs.sources

sudo apt update

The sources file currently served is:

Types: deb
URIs: https://roojs.github.io/repos/
Suites: @suite@
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/roojs.gpg

DNF (Fedora)

Repositories are published per Fedora release under rpm/fc<version>/<arch>/. Check your version with rpm -E %fedora.

sudo curl -fsSL https://roojs.github.io/repos/key.gpg \
  -o /etc/pki/rpm-gpg/RPM-GPG-KEY-roojs
sudo curl -fsSL https://roojs.github.io/repos/repo \
  -o /etc/yum.repos.d/roojs.repo
sudo dnf makecache

The repo file currently served is:

[roojs]
name=roojs packages (Fedora $releasever)
baseurl=https://roojs.github.io/repos/rpm/fc$releasever/$basearch/
enabled=1
gpgcheck=0
repo_gpgcheck=1
gpgkey=https://roojs.github.io/repos/key.gpg
